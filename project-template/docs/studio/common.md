# Общее для всех ролей

Producer вкладывает ссылку на этот файл в каждую спеку. Каждое правило стоило реального отказа.

- **Первой командой — установка зависимостей.** Иначе проверки не запускаются, а отчёт зелёный.
- **Работа не сделана, пока не закоммичена.** Перед отчётом: дерево чистое, в журнале ветки — твой
  коммит.
- **Пустой дифф по своей зоне = работа не сделана.** Пересказ карточки исполнением не является.
- **Проверка называется командой и кодом выхода**: «прогнал `<команда>` — код 0, 41 с», а не
  «тесты зелёные».
- **У каждого факта один владелец.** Нужен факт из чужой зоны — скажи в отчёте, не выводи у себя.
- **Границы спеки — запрет.** Чужие зоны не трогать.
- **Числа «до» и «после»** по каждой карточке. Порог, поднятый вместо починки, — дефект.
- **Первая строка отчёта — ответ на прямой вопрос спеки.** Дальше: что сделано, чем доказано, что
  осталось. Сомнение называть.
- **Лимит итераций — 2–3 на проблему** (гипотеза → правка → проверка). Не блокирует — изолировать
  (`it.skip` с комментарием `ponytail:`) и описать гипотезу для `bug-`-карточки; блокирует — вопрос
  Producer: симптом, что проверено, варианты с ценой.
- **Фоновые процессы с `&` и `wait` запрещены** — вешают воркера.
- **На общей машине останавливай только свои процессы** (по PID/командной строке своей задачи).
- **Отчёт — caveman full; код — ponytail full.** Документы, карточки, CHANGELOG, коммиты — обычной
  прозой (коммиты — Conventional Commits).
- Навыки проекта — `.claude/skills/`; читать только названные в роли или спеке.
