# Шаблон задания субагенту на блок работы

Скопировать и заполнить. Абзацы, помеченные «(под проект)», переписать под конкретный репозиторий.
Жирным — то, что нельзя выбрасывать: без этих строк блок дорожает или принимается на слово.

---

**ПРОЕКТ:** `<путь к репозиторию>` (ветка `<branch>`). Копия для прогонов: `<путь>`. Ответы и отчёты —
по-русски; комментарии в коде — по языку репозитория (под проект).

**ТЫ — роль `<роль>`** (контракт `<.claude/agents/роль.md>`): коротко — зона файлов и ключевые
запреты роли (не менять JSON попутно; local-функции до использования; строки игроку только через
свою функцию локализации; **НЕ коммитить, НЕ пушить, НЕ деплоить**).

**ЭКОНОМИЯ (платный API):** не читай `<базовые доки>` и файлы целиком — только указанные диапазоны.
Инструменты запускать `<команда>`; окончания строк: `<файл>` — `<CRLF/LF>`, проверить и восстановить.

**УЖЕ УСТАНОВЛЕННЫЕ ФАКТЫ (не проверять заново):** `<факт 1 — файл:строка>`, `<факт 2>`.
**ЧТО УЖЕ СДЕЛАНО:** `<готовые хелперы/функции с подписью и указателем>`. Подпись не менять.

**ЗАДАЧА — блок:**
1. `<правка 1 — файл:строка, точный текст/поведение>`
2. `<правка 2>`
3. Тесты: `<где и что должно проверяться; какими существующими помощниками пользоваться>`

**ПРОВЕРКА (обязательна, своими глазами):** `<команда тестов>` — без FAIL, сообщить точное N/N;
`<команда сборки/линтера>` — статус. Падает — почини до отчёта.

**ТВОИ ФАЙЛЫ:** `<список>` + отчёт `<docs/qa/<блок>-<роль>.md>`.
**НЕ ТРОГАТЬ:** `<список чужих файлов и областей>`.

**ОТЧЁТ** (файл `<путь>`, по-русски): что и где изменено (`файл:строка`), какие методы/факты
использованы и где подтверждены, своё число проверок, новые строки для перевода, чек-лист ручной
проверки (игровые имена/естественные названия, а не внутренние id), открытые вопросы.
**В финальном ответе кратко:** N/N, статус линтера/сборки, тронутые файлы, всё ли уложилось в список.

---

## Задание приёмке (отдельный агент)

- «Ты проверяешь, а не чинишь» + формат находки: где (`файл:строка`) / ожидание / наблюдаемое
  (с цитатой) / шаги / серьёзность / кому адресовано.
- Цели поиска перечислить: остатки удалённого кода, дрейф доков и переводов, места удалённого
  поведения в других ветках, слабые места тестов.
- **Обязательная проба мутацией:** внести намеренную поломку, требовать FAIL по этому месту, откатить
  по хешу, снова зелёный прогон — отчёт о трёх пробах.
- Границы: не править код/доки (кроме своих отчётов), ничего не коммитить и не деплоить; временные
  копии — вне репозитория.
- Вердикт в конце: принимаю / принимаю с замечаниями / не принимаю + список находок.
